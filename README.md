# FotoLeerSpel

Een eenvoudige webapp om te leren met foto's van je lesstof.

## Functies
- Foto uploaden per kaart
- Eigen vraag + antwoord per foto
- Quizmodus met willekeurige volgorde
- Directe feedback en score

## Starten
Open `index.html` in je browser of start een lokale server:

```bash
python3 -m http.server 8000
```

Ga daarna naar `http://localhost:8000`.
